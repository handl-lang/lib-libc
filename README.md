# lib-libc

sdkgen-generated libc FFI bindings — generic ports plus the `c-linux-x86_64`
adapters, emitted under `handl-packages/generated/` (a gitignored build
artifact). One module per C header (`libc/epoll.hnl` ← `sys/epoll.h`, …);
`specs/libc.sdkgen.yaml` narrows the surface per header basename.

Part of the `handl-lang` org split (ADR-0128). History is a `git subtree
split` of the platform monorepo's `generated/libc/` (via `c`).

## Layout

```text
src/        the .hnl sources
specs/      committed sdkgen inputs (libc.sdkgen.yaml)
handl-packages/generated/   build artifact — regenerated by the gate
pkg.hnl     dependencies, when any: `{ deps: { <name>: "branch:<ref>" } }`
```

## Regenerate

```bash
# one invocation per bound header — see LIBC_HEADERS in scripts/hnl-gate.sh
hnl sdkgen c /usr/include/sys/epoll.h \
  --output handl-packages/generated/libc \
  --config specs/libc.sdkgen.yaml
```

(needs libclang — set `LIBCLANG_PATH` if the loader cannot find it)

## Gate

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```

The gate regenerates `handl-packages/generated/` from `specs/` first, then
typechecks/lints/tests whatever `.hnl` sources exist.
